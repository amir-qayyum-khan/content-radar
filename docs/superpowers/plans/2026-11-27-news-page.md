# News Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/news/` page listing the top AI-video stories of the last 7 days from Hacker News and Reddit, refreshed by the nightly run.

**Architecture:** `scripts/news.ts` fetches and ranks stories with plain `fetch` (no LLM). `nightly` saves them to `data/news.json` before the build. The Astro page reads that file through `getSiteData()`.

**Tech Stack:** Node 24 + tsx, Vitest, Astro 7 (existing).

**Spec:** docs/superpowers/specs/2026-11-27-news-page-design.md

## Global Constraints

- No model calls, and no key required: Reddit is used only when `REDDIT_CLIENT_ID` and `REDDIT_CLIENT_SECRET` are set; otherwise it is skipped with one log line.
  (Recon on 2026-11-27: anonymous Reddit JSON returns 403 or a login redirect.)
- Window: last 7 days. The page keeps the top 60.
- Only `http:`/`https:` URLs. Links open in a new tab with `rel="noopener nofollow"`.
- One failing source never fails the run. If all sources fail, keep yesterday's `data/news.json`.
- The news step can never stop the build or publish.
- Hacker News queries use `typoTolerance=false` (recon: "sora" matched "Spray").
- Strip HN's `[video]` link tag before keyword matching: it marks the link type, not the topic.

## Review Focus

1. Hacker News API down or returning junk JSON ⇒ news step logs, keeps the old file, and the run still publishes. Test in Task 2.
2. A story title with `<script>` or a `javascript:` URL ⇒ the URL is dropped and the title is shown as text. Tests in Tasks 1 and 3.
3. The same link posted on both sources ⇒ shown once, at the higher rank. Test in Task 1.
4. No stories at all (quiet week or first run) ⇒ the page says so plainly and the build passes. Test in Task 3.
5. Reddit keys missing ⇒ HN-only list, with no error toast. Test in Task 1.

### Task 1: Fetch, filter and rank

**Files:**
- Create: `scripts/news.ts`
- Test: `tests/news.test.ts`

**Interfaces:**
- Produces:
  - `interface NewsItem { id: string; title: string; url: string; source: 'hn' | 'reddit'; where: string; score: number; comments: number; commentsUrl: string; postedAt: string /* ISO */; rank: number /* normalised */ }`
  - `isVideoNews(title: string): boolean`
  - `rankNews(items: NewsItem[]): NewsItem[]`: sets `rank = score / p90(score of that source)`, dedupes by URL (keeps the higher rank), sorts by rank desc then `postedAt` desc, and keeps 60.
  - `fetchNews(opts: { fetch?: typeof fetch; now?: Date; env?: Record<string, string | undefined>; log?: (s: string) => void }): Promise<{ items: NewsItem[]; okSources: number }>`

**Sources:**
- Hacker News: `https://hn.algolia.com/api/v1/search?query=<q>&tags=story&typoTolerance=false&numericFilters=created_at_i><now-7d>&hitsPerPage=50`.
  - One request per query in `NEWS_QUERIES = ['AI video', 'Sora', 'Veo', 'Kling', 'Runway', 'Pika', 'Luma AI', 'ElevenLabs', 'text-to-video', 'video generation', 'AI film', 'lip sync', 'Remotion']`.
  - Fields used: `objectID`, `title`, `url` (fall back to the HN item URL), `points`, `num_comments`, `created_at_i`.
  - `commentsUrl` = `https://news.ycombinator.com/item?id=<objectID>`.
- Reddit, only with keys:
  - Get a token: POST `https://www.reddit.com/api/v1/access_token` with basic auth and body `grant_type=client_credentials`.
  - Then GET `https://oauth.reddit.com/r/<sub>/top?t=week&limit=50`, with `User-Agent: content-radar/1.0`.
  - Subs: `aivideo` (kept whole), `VideoEditing`, `StableDiffusion`, `singularity`, `ElevenLabs` (title must pass `isVideoNews`).
  - Skip `over_18`.
  - `url` = the post's `url`; for self posts, the permalink.
  - `commentsUrl` = `https://www.reddit.com` + `permalink`.
  - `where` = `r/<sub>`.
- `isVideoNews`: after removing `[video]`, the title matches `/\b(video|film|movie|animation|animated|voice|tts|text-to-speech|lip.?sync|dubbing|sora|veo|kling|runway|pika|luma|elevenlabs|remotion|hailuo|seedance|wan ?2|midjourney video)\b/i`.

- [ ] **Step 1: Write the failing tests** in `tests/news.test.ts`. Use a fake `fetch` keyed by URL substring.
  - `isVideoNews`: true for `'Kling 3.0 makes 2-min videos'`; false for `'VCs complain about AI slop [video]'`.
  - `fetchNews` with no Reddit env: only HN URLs are requested, `okSources === 1`, and the log mentions `reddit: skipped`.
  - `fetchNews` drops an item with `url: 'javascript:alert(1)'` and keeps its siblings.
  - `fetchNews` with HN returning 500 for every query and no Reddit: `okSources === 0`, `items` is empty, and it does not throw.
  - `rankNews`: HN `[100, 10]` and Reddit `[5000, 500]` give the two top items (one per source) a rank of about 1, and a total of 4 items.
  - `rankNews`: the same URL from HN (score 50) and Reddit (score 5000) appears once.
  - `rankNews`: 70 inputs give 60 outputs.
  - With Reddit env: the token POST carries `Authorization: Basic <base64 id:secret>`, and an `over_18` post is skipped.
- [ ] **Step 2:** `npx vitest run tests/news.test.ts`. Expected: FAIL, cannot find module.
- [ ] **Step 3:** Implement `scripts/news.ts` per the interfaces above. p90 = the value at index `floor(0.9*(n-1))` of the sorted scores, minimum 1.
- [ ] **Step 4:** `npx vitest run tests/news.test.ts`. Expected: PASS.
- [ ] **Step 5:** Commit `feat: fetch and rank AI video news`.

**Page:**
- Title "AI video news". A sub-line gives the window and the update time.
- A Top/Newest toggle reuses the sort-control pattern from `Filters.astro`. It sorts rows client-side by `data-rank` or `data-posted` and is synced to `?sort=`.
- Each row is an ordered list item with:
  - the rank number;
  - the title as an `<a target="_blank" rel="noopener nofollow">`;
  - a source chip ("Hacker News" or `r/aivideo`);
  - `▲ score`;
  - a comments link (`N comments`);
  - the age via the existing `ago()`.
- Empty state: "No video stories this week yet. The list refreshes daily at 04:00 PKT."
- Styling uses the existing tokens only.
