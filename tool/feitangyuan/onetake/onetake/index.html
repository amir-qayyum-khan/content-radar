What it does

onetake builds short motion films (10-30 s, narrated feature demos up to about 60 s) about a product, skill or app. It uses a single HTML composition driven by time, a library of motion moves, synthesised sound effects and an oracle that flags slideshow-like pacing. It renders frame by frame with motion blur (1080p30 drafts, 4K60 finals) and can add voice-over, subtitles and other language versions.

Where it fits your pipeline

It does not fit the Kling-and-ffmpeg drama pipeline well. It is built for product and skill launch clips, not narrative episodes, and it says talking-head and editing existing footage are out of scope. The nearest fit is the pacing-edit stage, as a source of pacing ideas (measuring a reference's rhythm, hard cuts only where they mean something, beats that carry into each other). It could also make a promo or teaser for the series. It does not generate drama footage, and its licence is noncommercial.

Install

  • git clone https://github.com/feitangyuan/onetake

Then copy the skill's folder into ~/.claude/skills/.

How to use

Use onetake to make a 15-second teaser for my skill. First analyze this reference clip (ref.mp4), then give me three different concepts with looks to choose from before building anything.

The reference is analyzed (energy map, cuts, stillness) and you get three concepts, each with a hook frame, what carries each beat into the next, and a look preset. After you pick one, it builds the HTML composition, renders a draft, and the oracle checks rhythm and carry. The result is a short rendered motion film with synthesised sound.
