What it does

reanimate is a Claude Code skill that reverse-engineers web animations from a live site, screen recording, mp4, gif or Lottie file. It records the original in a headless browser, rebuilds it in your code (CSS, Framer Motion, GSAP, three.js), then records the copy the same way and compares timing, easing and pixels. It repeats for about 2 to 5 rounds until the copy matches.

Where it fits your pipeline

It does not fit the story, Kling or ffmpeg steps of a micro-drama pipeline directly. It is a web and UI animation cloner that outputs front-end code, not video clips. At most it could help build animated title cards, lower thirds or on-screen UI elements for an episode, which you would render separately. Its record, compare and repeat loop is a pattern worth borrowing for automated review, but the skill itself does not score Kling clips or fix pacing. It runs on macOS or Linux (Windows is untested), and you are on Windows.

Install

  • npx skills add NiazMorshed2007/reanimate -g

Then copy the skill's folder into ~/.claude/skills/.

How to use

/reanimate this loader, 0:03 to 0:05 of ~/Downloads/loader.mov, into components/Loader.tsx

Claude records the reference, writes a spec of each element's timing and easing, builds the animation in your project's stack, then films its copy and compares it with the original. You get the code plus a report listing any differences that remain after the rounds.
