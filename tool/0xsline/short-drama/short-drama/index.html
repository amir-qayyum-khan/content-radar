What it does

Short-drama is a Claude Code skill that guides you through writing a full 50-100 episode micro-drama script using slash commands. It covers genre selection, story plan, characters, episode outline, episode scripts, quality review, export, an overseas (English) mode and a compliance check. Progress is saved in project files and a state file, so work resumes across sessions.

Where it fits your pipeline

It slots into step 1 and 2 (idea to story, story to episodes), before reference images and Kling. It targets the slow, robotic story problem with opening rules for hooking in the first 30 seconds, a rhythm curve, a payoff (satisfaction) matrix, paywall cliffhanger placement and per-episode hook design. /review gives an automated script quality score that can cut manual review of the writing. Episodes are written as 800+ character scripts, so you would need to condense them to fit 1-minute episodes. The README does not mention any Kling or ffmpeg output.

Install

  • git clone https://github.com/0xsline/short-drama

Then copy the skill's folder into ~/.claude/skills/.

How to use

/start (then pick genres such as revenge plus hidden-identity, choose tone, ending and episode count, then run /plan, /characters, /outline, and /episode 1)

Saved files in your project: creative-plan.md, characters.md, episode-directory.md, and episodes/ep001.md and so on. Each episode has 3-5 scenes, shot-type cues, tagged dialogue and an ending cliffhanger. /review scores each episode on a 50-point scale, and /export produces one combined script file.
