What it does

OpenChatCut is an open-source (AGPL-3.0), local-first AI video editor with a real multitrack timeline. Claude Code, Codex, or a built-in agent can read, edit, and export projects through shared tools (MCP). Edits are written as real tracks, clips, transitions, captions, and effects, so you can keep editing by hand, undo, or hand the project to another agent. It also offers transcript-based cutting, captions, music and sound effects, motion graphics, and exports to MP4, audio, captions, and FCPXML.

Where it fits your pipeline

Slots in after step 4 (Kling clips), as an alternative or complement to the plain ffmpeg join in step 5. It improves pacing-edit by giving an agent a real timeline for cut timing, zooms, transitions, music, SFX, and captions, instead of a flat concatenation. It also touches music-sfx and captions-publish. Because edits stay visible and undoable, review is faster than redoing an ffmpeg script. It does not fix the story or hook itself.

Install

  • git clone https://github.com/0xsline/OpenChatCut.git
  • npx skills add 0xsline/OpenChatCut

Then copy the skill's folder into ~/.claude/skills/.

How to use

Open my project with the 20 Kling clips for episode 3. Tighten the cuts so each shot lasts 1.5 to 3 seconds, add a punch-in zoom on the final reveal, put a riser and a hit sound effect before the cliffhanger, add burned-in captions, and export a vertical MP4.

The agent edits the clips on the OpenChatCut timeline. You get trimmed cuts, zoom keyframes, transitions, sound effects, and captions, all still editable. You can preview and undo any change, then export MP4 or FCPXML. The README does not show how well it judges pacing on its own, so review the cuts yourself.
