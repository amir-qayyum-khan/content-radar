What it does

Motion Design Skill teaches an AI agent motion-direction principles: timing, easing, choreography and emotional intent. It includes a checklist, personality archetypes, duration and easing tables, and ready-made animation patterns. It is written for UI animation (CSS, Framer Motion, GSAP, Lottie), not live-action video or drama pacing. Rendered MP4 or GIF output needs a separate Creator MCP connection.

Where it fits your pipeline

It fits after step 5, when ffmpeg joins the clips, and only for graphic overlays: title cards, captions, end cards and animated stingers. It helps those elements feel deliberate, with better timing and easing. It does not address the main problem of slow, robotic story pacing, because it is built for UI animation and has no hooks, beat sheets or shot-cut guidance. It is a marginal fit for this pipeline.

Install

  • npx skills add LottieFiles/motion-design-skill

Then copy the skill's folder into ~/.claude/skills/.

How to use

Design the motion for my episode title card and end-of-episode 'To be continued' cliffhanger card. Use a tense personality, and give timing, easing and choreography for the text entrance, a quick glitch-style accent, and a hard cut-out.

A motion plan and animation code (for example CSS or GSAP) with durations, easing curves, stagger order and emotional rationale for each element. It is aimed at overlay graphics such as titles, lower thirds and end cards. It will not make the story paced faster or generate any video. Exporting to MP4 needs the separate Creator MCP.
