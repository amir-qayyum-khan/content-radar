What it does

raea is a render engine where your AI writes React and TypeScript compositions that render to video, motion graphics, 3D or games on your own GPU. It ships a CLI (raea render, raea check, raea cut) and installs agent skills into ~/.claude/skills so Claude Code can write, render and check raea projects. The engine and app are free to use. Paid Pro and Team plans add cloud storage, search and publishing.

Where it fits your pipeline

It could replace or follow step 5, the ffmpeg join, after Kling has generated the clips. Cut timing, speed curves, freeze frames, text overlays and sound mixing become code that Claude can iterate on. raea check automates part of the slow review step by flagging freezes, loudness problems and text issues before anyone watches. It does nothing for story or hook writing, and it does not generate Kling-style footage. The readme says the app is unstable, especially on Linux and Windows.

Install

  • git clone https://github.com/shinyobjectz/raea

Then copy the skill's folder into ~/.claude/skills/.

How to use

Using raea, build a 60-second vertical episode from my 3-second Kling clips in ./clips. Open with a 2-second hook title card, vary the cut length and speed up the cuts as tension rises, add burned-in captions, then run raea check and fix anything it flags.

A raea React/TypeScript composition file and a rendered mp4. Claude should also report the raea check results on clipped text, low contrast, unsafe areas, freezes and loudness, and fix what it finds. Whether raea can ingest Kling clips this way is not stated in the readme, so expect some trial and error.
