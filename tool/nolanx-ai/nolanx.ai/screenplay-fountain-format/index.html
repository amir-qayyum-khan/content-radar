What it does

This skill tells Claude to write screenplays and scene text in clean Fountain syntax. That means standard scene headings (INT./EXT.), uppercase character cues, dialogue right after the cue, sparse parentheticals and filmable action lines. It lives inside the NolanX filmmaking agent repo and is meant for the planner and script_writer agents. The output is exportable script text that can also anchor storyboard sequences.

Where it fits your pipeline

It slots into step 2 (story to episodes), right after the idea is turned into a story. It gives each episode script a consistent, filmable structure with clear scene geography. That makes it easier to break scripts into reference images and 3-second Kling shots. It does not by itself add hooks, energy or rising tension. Pair it with a hook or beat-sheet skill for that. Note that the skill is built into the NolanX agent runtime. The README does not say how to use it as a standalone Claude Code skill, so installing the full repo is the only documented route.

Install

  • git clone https://github.com/nolanx-ai/nolanx.ai

Then copy the skill's folder (.nolanx/skills/screenplay-fountain-format) into ~/.claude/skills/.

How to use

Write episode 1 of my micro-drama as a Fountain screenplay: a woman finds her husband's second phone in the first 5 seconds. Keep action lines short and filmable, end on a cliffhanger, and use a new scene heading whenever location or time changes.

A Fountain-formatted script with INT./EXT. scene headings, uppercase character cues, dialogue directly under each cue, few parentheticals, concise visual action lines and blank-line beat separation. Each scene heading can serve as a sequence anchor for storyboard prep. The skill only sets format and style, so hook strength and pacing still depend on your prompt.
