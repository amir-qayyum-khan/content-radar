What it does

Agent Sprite Forge is a set of agent skills that turns one approved master still into game-ready 2D sprites, maps, code-drawn pixel art and video-derived animation. It uses image and image-to-video generation routes (API keys or a signed-in Codex or Grok CLI) plus deterministic Python tools to key, loop, retime and package the results for Godot, Aseprite or web games. It is built for game development, not for live-action micro-drama.

Where it fits your pipeline

Weak fit. It would slot loosely after step 3 (reference images) as a way to make a consistent character master still and short keyed action clips. It does nothing for the main problems of slow story, pacing, hooks or review, and its output targets game engines rather than Kling clips or ffmpeg episodes. Useful only if the creator wants stylized 2D or pixel-art animated drama.

Install

How to use

Using generate2dsprite, make a master still of my hooded heroine from this reference image, then use video2dsprite to produce idle, run and attack loops I can use as animated character cutouts.

An approved master still, then one image-to-video clip per action, keyed with a transparent background, looped and retimed, and packaged as a spritesheet or animation.json with a CREDITS.txt. Output is game-style sprite assets, not finished drama footage.
