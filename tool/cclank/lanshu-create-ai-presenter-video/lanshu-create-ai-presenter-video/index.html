What it does

This skill turns a topic or finished script into a publish-ready explainer video. It either uses an AI presenter built from an authorized adult portrait, or it runs faceless in one of twelve explainer styles (nine visual, three narrative). It locks the narration as the master clock, then produces the master video, a share copy, captions, and QA notes. It is built for explainers, not promos or ads.

Where it fits your pipeline

It is mainly an explainer-video tool, so it fits this micro-drama pipeline only loosely. It covers story to finished video for explainers, not drama. Its narration-as-master-clock timing, captions and separate machine and visual QA notes could inform your pacing and review steps. It does not target hooks or rising tension, and it is not built for Kling clip assembly. Its styled route is 16:9 only.

  • git clone https://github.com/cclank/lanshu-create-ai-presenter-video

Then copy the skill's folder into ~/.claude/skills/.

How to use

Make a 16:9 faceless explainer about how KV cache works in LLMs. Show me the style menu and recommend two or three styles, then write the script in the style I pick.

The agent shows the style gallery and the twelve-style menu, and recommends a few styles with one reason each. After you pick one, it writes a script suited to that style and states any paid-call details before it spends anything. It then builds the film with captions and delivers a master video, a smaller share copy, and QA notes.
