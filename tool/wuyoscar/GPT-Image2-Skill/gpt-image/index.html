What it does

gpt-image is a prompt gallery, two agent skills and a CLI for generating and editing images with OpenAI's GPT Image models (defaults to 2.6 Flare). The gpt-image skill creates and edits images from prompts and reference images, and can slice sprite sheets into GIFs. The get-prompt-from-image skill extracts a reusable prompt from an existing image.

Where it fits your pipeline

Slots in at step 3, after the episodes are written and before Kling. It produces cast, wardrobe, location and prop reference images, and its character-sheet prompts help keep faces and outfits consistent across clips. get-prompt-from-image can reverse-engineer a prompt from a still you like, so you can reuse its look. It does not help with story, pacing or review.

Install

  • /plugin marketplace add wuyoscar/gpt_image_2_skill

How to use

Use gpt-image to make a character reference sheet for my micro-drama lead, Ling Yuan: a young woman in a dark red trench coat, front, side and back views, plus three facial expressions, on a plain background.

Claude runs the gpt-image CLI and saves a character sheet image (PNG). You can refine it with follow-up edit prompts, or use get-prompt-from-image to turn a still you like into a reusable prompt. The CLI needs OPENAI_API_KEY set.
