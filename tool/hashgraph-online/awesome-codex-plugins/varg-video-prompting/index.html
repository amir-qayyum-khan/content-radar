What it does

This skill teaches Claude how to write prompts for varg's video, image, voice and music models so shots come out right in one or two takes. It covers a working loop (references, look bible, character sheets, approved stills, audio lock, animate, QA), which model suits which shot, prompt structure, what reference tags like @image1 and @video1 copy, dialogue rules, and a frame and audio QA checklist.

Where it fits your pipeline

Slots in after Story -> episodes and wraps steps 3 and 4 (reference images and Kling or Seedance clip generation). It improves first-take quality by locking approved stills, character and location text before paid video runs, and adds a frame and audio QA checklist that can speed up the slow review step. It does not write the story or fix pacing and hooks itself, though it plans shots around a beat grid and locked audio. Note that it targets varg's hosted models, so it would replace or sit beside the direct Kling step rather than feed it.

Install

  • /plugin marketplace add hashgraph-online/awesome-codex-plugins

Then copy the skill's folder (plugins/vargHQ/skills/varg-video-prompting) into ~/.claude/skills/.

How to use

Use varg-video-prompting to plan a 60-second micro-drama episode: a woman in a green rain jacket finds a note on her door. Give me a frozen character paragraph, still prompts, and a Seedance prompt for a 5-second cliffhanger shot with a hook in the first second.

A structured plan: a frozen character and location text, still-image prompts to approve first, a video prompt with reference roles, camera and blocking, a no-text line, a model recommendation per shot, and a QA checklist. Costs would be estimated in credits before any batch run.
