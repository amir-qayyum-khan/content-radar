lipsync

Lip-syncs an existing real-person video to new speech or a script using sync.so, outputting a matched MP4.

What it costs

The README doesn't say what it costs.

What it does

Lipsync takes one existing video of a real person and re-times the mouth to match new speech. The speech can be a voiceover, a re-recorded take, a song, or a typed script voiced by sync. labs (sync.so). It returns one MP4 and handles length mismatches, multiple faces, and cost quotes before it generates anything.

Where it fits your pipeline

Slots in after the clips for a scene exist and before the ffmpeg join, but only for real filmed footage of a person. The README says it is not for AI-generated characters or Kling clips, which belong to a different skill (ai-video-to-talking). For the Kling-based pipeline it is therefore of limited direct use. It helps if you mix in real actor footage and need dialogue changed or fixed without a reshoot, which makes the voice feel natural and cuts re-record time. It does not address the hook or pacing problems in the story.

Install

  • /plugin marketplace add hashgraph-online/awesome-codex-plugins

Then copy the skill's folder (plugins/synchronicity-labs/skills/skills/lipsync) into ~/.claude/skills/.

How to use

Lipsync my clip scene3_actor.mp4 to the re-recorded line in take2.wav. The speech is a bit longer than the video, so use bounce. Show me the cost estimate before you start.

Claude saves both files as sync. assets, checks input quality (for example several faces or music under the voice), and quotes the estimate using the sync-3 model. After you approve, it creates the lipsync job, waits for it to finish, and gives you the output MP4 URL. In a shell it can also offer to download the file next to the source.
