What it does

Keeps an AI video project in a private GitHub repo without the creator needing to know git. The agent creates the repo, keeps API keys out, saves a version after each approved step, and stores large video and audio files as GitHub Releases uploads so the 100 MB limit never applies. It also sets up a standard folder layout, logs the prompt, model, seed and cost of every take, and offers undo and restore on a new laptop.

Where it fits your pipeline

Slots in at the start of the pipeline and runs alongside every step after it, covering story, episodes, reference images, Kling clips and the ffmpeg join. It does not improve story quality or pacing. It protects your work with versioned saves and undo, keeps Kling prompts, seeds and costs on record, and keeps references and clips organized for review. That makes it easier to go back to an earlier take or compare takes. Review stays manual.

How to use

Put my micro-drama project on GitHub as a private repo, organize the folders for script, characters, shots and edit, and save a version after each step I approve.

The agent checks that git, gh and Python 3 are installed and walks you through a one-time GitHub sign-in. It then creates a private repo with a standard folder layout and a .gitignore that keeps keys out, and runs a proof step that restores a test copy to confirm the backup works. After that it saves each approved step, with each take logged with its prompt, model, seed and cost, and ends each save with a line such as 'Saved as version 12, backed up.'
