What it does

HyperFrames is HeyGen's open-source framework that turns HTML, CSS, JavaScript and seekable animations (such as GSAP) into deterministic MP4 videos. The plugin gives Claude Code skills for building compositions, captions, voiceovers, transitions and overlays. It also has skills for remaking existing videos and for porting Remotion projects.

Where it fits your pipeline

It slots in after step 4 (Kling clips) and replaces or augments the ffmpeg join in step 5. It improves pacing-edit and captions-publish: you get frame-level control over cut timing, shader transitions, overlays and animated captions. You can also ask for changes like a faster cut or a bigger title, and only that part is regenerated. It does not write the story or fix the hook and tension problem at script level, and the README does not describe automated review or QC. Preview is still a manual check.

Install

  • /plugin marketplace add heygen-com/hyperframes
  • npx hyperframes init my-video
  • npx hyperframes preview
  • npx hyperframes render

How to use

Using /hyperframes, create a 60-second vertical micro-drama episode from these 20 Kling 3-second clips in ./clips. Open with a hard-cut hook in the first 2 seconds, vary the cut timing, add flash-through-white transitions on the tension beats, and burn in animated captions from the dialogue.

A HyperFrames project folder (HTML composition) with the clips sequenced and timed, transitions and captions added, and a live preview you can open in the browser. You then render it to MP4 with npx hyperframes render. Requires Node.js 22+ and FFmpeg. Results depend on your clips and prompt, and I could not verify how well it handles story pacing.
