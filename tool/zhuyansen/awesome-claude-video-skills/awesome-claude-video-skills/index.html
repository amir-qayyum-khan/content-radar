What it does

A curated directory of open-source skills, plugins and toolkits that let Claude Code, Codex and other coding agents make video (HyperFrames, Remotion, motion graphics, editing, explainers, avatars, short dramas). It is a list of 561 repos, graded by README, plus a 16-skill end-to-end test on one 15-second promo. It is not a skill itself, so you use it to choose which video skill to install.

Where it fits your pipeline

It is not a pipeline step. Use it before or between steps to find tools. The Stories & animation and Scripts & learning sections may help story-script, the Editing and Shorts & social sections may help pacing-edit and captions-publish, and the Avatars section may help voice-emotion. It does not directly improve pacing or review. Its test only checks that a film plays, has the right length, shows the copy and moves, and does not score how good it looks. Note that it found Claude Code with no skill passed the same checks, so a skill only helps if it adds a look, a workflow or footage to edit.

Install

  • git clone https://github.com/zhuyansen/awesome-claude-video-skills

Then copy the skill's folder into ~/.claude/skills/.

How to use

Using the Stories & animation list in awesome-claude-video-skills, which skills suit vertical 1-minute micro-drama episodes built from Kling clips, and which add cut timing, sound or captions?

A short shortlist of candidate repos from the Stories & animation, Editing and Shorts & social sections, with what each does. You then install the ones you pick from their own repos. The README gives no install commands for the list itself.

How it works

Claude skills and plugins for video and audio creators, refreshed every morning from public GitHub data. Read a tool's source before you install it.
