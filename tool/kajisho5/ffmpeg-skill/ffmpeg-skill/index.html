What it does

ffmpeg-skill gives Claude Code a local video editor built on FFmpeg. It ships 42 typed tools (cut, join, silence removal, fit to duration and aspect, captions and karaoke, loudness, platform exports) and follows a probe, edit, verify workflow. It can also write a local HTML review page showing each step, its checks, and the result in a phone frame.

Where it fits your pipeline

Slots in at step 5, after Kling generates the 3-second clips, replacing hand-written ffmpeg joins. It improves assembly: joining clips, removing dead pauses, fitting to 1 minute and 9:16, loudness, and burned-in captions. Its review page also speeds up the slow manual review step. It does not decide what to cut or fix weak story or pacing, so the hook and tension problem still has to be solved earlier in the script.

Install

  • npx ffmpeg-skill setup
  • npx ffmpeg-skill doctor

How to use

Join the clips in ./episode3 into one 9:16 episode, trim the silences, normalise loudness to -14 LUFS, burn in my captions from captions.srt, then show me the review page.

A single rendered vertical episode file. Claude probes the clips first and checks the output's duration, frame size and audio afterwards. It also builds a local HTML review page with the sources, each step's checks, the result in a phone frame with the platform safe area, and a timeline. You can press a clip or caption number, type what should change, and copy that instruction back to Claude.
