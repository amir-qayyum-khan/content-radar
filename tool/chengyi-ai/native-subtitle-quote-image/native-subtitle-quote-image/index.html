What it does

Turns real video frames into tall quote images (JPG) with subtitle strips stacked under a main frame. It has two modes: native mode crops subtitles already burned into the video pixels without redrawing them. Script mode draws reviewed lines onto real frames and labels them as post-production subtitles. It works from a local video or a YouTube link (via yt-dlp), and it also ships Python scripts you can run directly.

Where it fits your pipeline

This is a side tool, not a core step. It fits after the Kling clips are joined into an episode by ffmpeg (step 5), as a way to make promo or recap stills of key lines with real frames. It helps with captions and publishing, such as teaser posters and shareable quote cards, and it speeds up picking frames through contact sheets. It does not fix the story hook or pacing problems. It also assumes the video already has burned-in subtitles, or reviewed script lines you supply.

Then copy the skill's folder into ~/.claude/skills/.

How to use

/native-subtitle-quote-image Use this local video with burned-in Chinese subtitles to make a native-subtitle 3:4 quote image with 5 lines.

Claude first checks the source, subtitle type and candidate frames, and asks you to pick native or script mode if you haven't. You then get one JPG per image at the chosen ratio. Native mode also gives a timestamp JSON. Script mode gives a lines JSON. Multi-image jobs add a final_contact_sheet.jpg overview.
