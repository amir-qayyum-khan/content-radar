What it does

A set of 13 research skills that let Claude pull public social data (TikTok, Instagram, YouTube, Reddit, X, ad libraries and more) through the ScrapeCreators API. It finds outlier posts, mines comments, summarizes transcripts, tears down competitors and ads, and spots trends. Outputs are cited, baseline-aware artifacts such as hook lists, patterns, test ideas or CSVs.

Where it fits your pipeline

Slots in before step 1 and step 2 (idea to story, story to episodes). Use outlier-post-finder, transcript-intelligence and trend-discovery to learn which hooks and formats actually hold attention in short vertical drama. Use comment-mining to get exact audience language, objections and what viewers want next, which can help with the slow, robotic pacing and missing hook. It does not generate, edit or review clips, so it doesn't speed up the Kling, ffmpeg or manual review steps. It needs a paid ScrapeCreators API key, and only public data is available.

Install

  • npx skills add ScrapeCreators/social-media-research-skills

How to use

Find the outlier posts for @starterstory on YouTube Shorts from the latest page of videos, then analyze their transcripts and pull out the best hooks, opening lines and reusable story angles.

A cited list of videos that beat the creator's own baseline, with source URLs, verbatim hook quotes from the transcripts, recurring patterns and recommendations or test ideas you can reuse.
