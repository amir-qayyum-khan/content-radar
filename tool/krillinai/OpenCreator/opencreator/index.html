What it does

OpenCreator (formerly KrillinAI) is an open-source local AI workspace for creators. It uses Codex CLI as its agent engine and adds a visual workspace, a desktop app and reusable Skills. It covers script writing, image and video generation, text-to-speech voiceovers, video translation and dubbing, and subtitle editing. It is not a Claude Code plugin, and the README does not describe a drama-specific workflow.

Where it fits your pipeline

Slots in at the story-to-episodes step (idea to script), where its short-video scripting tool can draft episode scripts. Its image generation, video generation, text-to-speech and subtitle tools could also support later steps. It does not clearly cover Kling clip generation, ffmpeg joining or automated review, and nothing in the README shows it fixing slow pacing or weak hooks beyond what your prompts and the model provide.

Install

  • git clone https://github.com/krillinai/OpenCreator.git

Then copy the skill's folder into ~/.claude/skills/.

How to use

Open the OpenCreator Dashboard, choose the short-video script tool, and ask for a 1-minute micro-drama episode script with a hook in the first 3 seconds, a beat every 3 seconds, rising tension and a cliffhanger ending.

A short-video script drafted inside OpenCreator's workspace, saved as a version you can revise and compare. The README does not say whether it produces beat sheets or 3-second shot splits, so you may need to prompt for that structure. Output quality depends on the model configured through your local Codex setup.
