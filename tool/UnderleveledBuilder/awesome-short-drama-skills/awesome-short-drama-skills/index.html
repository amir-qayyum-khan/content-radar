What it does

awesome-short-drama-skills is a curated, hand-checked list of about 121 agent skills for AI short drama and manju. It covers novel adaptation, episode outlines, hooks and paywall beats, script review, storyboards, character assets, and prompts for video models such as Seedance, MiniMax and Kling. The repo also includes a short-drama-skill-finder skill, so your agent can recommend which listed skill to install for your task. The list itself is not a production tool. The skills it points to are separate projects.

Where it fits your pipeline

Use it before the story-to-episodes steps, as a way to choose tools. It points you to skills that strengthen idea to story and story to episodes (hooks, beat structure, cliffhangers, script review). It also lists storyboard and Kling/Seedance prompt skills for the reference-image and clip steps. It can speed up review indirectly by pointing to script-review checklists. It does not do clip scoring or ffmpeg editing. The README's own tests say the hook results are mixed: judges disagreed on episode-end hooks, and the README says control runs without any skill were sometimes stronger.

Install

  • git clone https://github.com/UnderleveledBuilder/awesome-short-drama-skills

Then copy the skill's folder into ~/.claude/skills/.

How to use

I make 1-minute vertical micro-dramas with Kling clips. My stories feel slow and robotic with no hook or rising tension. Which short-drama skill should I install for hooks, cliffhangers and script review, and how do I use it?

A shortlist of matching skills from the curated list, for example the writing and review skills the README ranks in its screenwriting tests. Each comes with its repo, what it fixes (hooks, paywall beats, episode-end cliffhangers, script review) and its own install command. Check each skill's SKILL.md before installing. This is a recommendation, not a rewritten script. The install command for the finder skill itself is not among the approved commands, so check the repo README for it.
