What it does

This is a Remotion repo-internal skill that captures matching 2x Remotion Studio timeline screenshots (before and after a layout change) and builds a before/after wipe reveal video in the repo's packages/brand package. It covers framing, a historical baseline checkout, a clamped cropRight interpolate animation, rendering to MP4, and uploading to R2. It is specific to the Remotion monorepo's own timeline UI comparison videos, not a general-purpose editing tool.

Where it fits your pipeline

Weak fit for the micro-drama pipeline. It is tied to the Remotion monorepo (packages/brand, packages/jonnys-videos, R2 upload skills) and is meant for UI comparison videos, not drama episodes. The only reusable idea is the Remotion pattern of a deterministic before/after wipe using interpolate() and useCurrentFrame(), which could inspire a reveal transition after the ffmpeg join step. It does not improve story hooks, pacing or review.

Install

  • npx create-video@latest

Then copy the skill's folder (.agents/skills/timeline-layout-reveal) into ~/.claude/skills/.

How to use

Use the timeline-layout-reveal skill to capture before and after 2x screenshots of the Remotion Studio timeline for RollerSkiCommute-new at frame 2025, then build the 6 second wipe reveal in packages/brand and render it to MP4.

Two matching 2560x1600 screenshots, an updated TimelineLayoutReveal composition with a before layer under an after layer wiping via cropRight from 1 to 0, and a rendered h264 MP4 at out/timeline-layout-reveal.mp4. Optionally an R2 upload link if requested.
