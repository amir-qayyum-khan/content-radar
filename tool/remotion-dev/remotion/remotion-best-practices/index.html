What it does

remotion-best-practices is a router skill for Remotion, a framework that builds videos from React code. It tells Claude which sub-skill to load for each task: creating a project, writing markup, captions, rendering, Studio preview, maps, multimedia, licensing and upgrades. It also sets rules such as opening Studio to preview and only rendering when explicitly asked.

Where it fits your pipeline

Slots in after Kling generates the clips, as an alternative to the plain ffmpeg join in step 5. It gives you editable cut timing, zooms, transitions and captions in code with a live Studio preview. That should make pacing less robotic and speed up review, since you can scrub and adjust instead of re-rendering blindly.

Install

  • npx create-video@latest

Then copy the skill's folder (packages/skills/skills/remotion-best-practices) into ~/.claude/skills/.

How to use

Create a new Remotion video: a 60-second vertical micro-drama episode that joins twelve 5-second Kling clips with hard cuts, a punchy zoom on each beat, and burned-in captions. Open Studio so I can preview it.

Claude sets up a Remotion project and writes React compositions that sequence your clips with the cut timing and zooms you described. It adds captions and opens Remotion Studio for preview. It renders to MP4 only if you explicitly ask for it.
