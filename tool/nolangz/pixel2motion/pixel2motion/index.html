What it does

pixel2motion turns a raster logo (PNG, JPG, WebP or screenshot) into a clean, minimal, smooth SVG. It then choreographs that vector into a logo animation, delivered as a standalone JS-rendered HTML file, using Disney's 12 animation principles. It also writes a motion spec and saves QA frames as evidence. It is built for logo reveals, splash screens, brand intros and loading or hover motion.

Where it fits your pipeline

It is a side branch of the pipeline, not part of the story-to-episode flow. Use it once to make a branded intro or outro sting for the series, then join that clip to each episode with ffmpeg at the final step. It doesn't improve story, hook or pacing inside the episodes. It only gives each episode a more polished brand open or close. It outputs HTML, so you would need to screen-record or render it to video before ffmpeg can use it. The README doesn't say it exports video.

How to use

Use pixel2motion on logo.png, my micro-drama channel logo. Vectorize it into a clean SVG and make a swift, confident 1.5 second splash reveal I can use as an episode intro.

You should get logo.svg (a smooth, motion-ready static vector) and logo_motion.html (a standalone animated reveal with replay, slow and speed controls). You should also get motion_spec.md (personality words, timeline, easing tokens) and QA images (fit overlays and a motion strip). The animation ends exactly on the verified static vector.
