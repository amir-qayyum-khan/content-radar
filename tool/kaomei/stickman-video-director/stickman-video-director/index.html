What it does

Stickman Video Director is an agent skill that turns an idea, article, link or script into a finished stickman-style video, including script, voiceover, captions and sound. It offers 16 visual styles and two modes: a Model Engine that uses video generation models for clips, and a Code Engine that animates layered assets and renders locally. It supports 16:9 and 9:16 output.

Where it fits your pipeline

It is an end-to-end generator, so it fits best as a fast alternative or a side experiment for faceless stickman content. It is not a drop-in step for a Kling reference-image pipeline. It covers idea to script and storyboard (story-script), and in Code Engine mode it also handles layered assets, animation, voiceover, captions and local rendering. It may improve pacing with its timeline control, and its script approval step helps catch a slow story before rendering. It does not document hook, cliffhanger or tension tooling, and the README excerpt does not show automated QC. Its Model Engine scene prompts could be adapted for Kling, but this is untested.

How to use

Help me install this skill: https://github.com/kaomei/stickman-video-director. After installation, read SKILL.md and tell me you're ready. Then make a 9:16 Survival Thriller style stickman video from this idea: a hiker hears footsteps behind them at night. Use the Code Engine, show me the script and a 20s sample first, and open with a hook in the first 2 seconds.

Claude checks the setup and asks you to confirm the script and a roughly 20 second sample in the chosen style. After you approve, it prepares the assets, animates them, adds captions and audio, and renders a finished vertical video file. In Model Engine mode you get a storyboard script and scene prompts instead, or generated clips if a video model is available.
