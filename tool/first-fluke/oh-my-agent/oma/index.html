What it does

oh-my-agent (oma) is a multi-agent toolkit that turns Claude Code and other coding agents into a team of specialists: planner, engineers, reviewer and debugger. The plugin bundles about 32 skills, such as oma-video, oma-voice, oma-image, oma-slide, oma-brainstorm, oma-pm, oma-qa and oma-translation. It also bundles 12 agent roles and hooks. It is mainly software-oriented, so only a few skills are likely relevant to micro-drama production, and the README does not say what oma-video or oma-voice actually do.

Where it fits your pipeline

Slots in at the start, after the raw idea and before episodes: oma-brainstorm and oma-pm can help shape the idea into a story and episode plan, and oma-qa can act as a review pass on outlines. oma-image, oma-video and oma-voice may touch reference images, clips and voice, but their behavior is unclear from the README, so treat those as unverified. It does not obviously replace Kling or ffmpeg, and it is not a dedicated hook or pacing tool, so it only partly addresses the slow, robotic pacing problem.

Install

How to use

Use oma-brainstorm to turn my idea (a jilted heiress discovers her fiance's secret twin) into a 10-episode micro-drama outline. Each episode should be 60 seconds, open with a hook in the first 3 seconds and end on a cliffhanger. Then use oma-qa to review the outline for slow pacing and flat tension.

A structured brainstorm of story directions and an episode outline, followed by a review pass that flags weak spots. Quality of hooks and pacing is unverified, because the skills are general-purpose and not screenwriting-specific. Read the oma-video, oma-voice and oma-image skill docs before relying on them for clip or audio work.
