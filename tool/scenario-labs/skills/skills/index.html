What it does

Scenario Agent Skills is a large collection of Agent Skills that teach Claude Code how to use the Scenario MCP server to generate images, video, audio, 3D assets and custom-trained models. It includes skills for storyboards, character consistency, Kling and other video models, video assembly, captions, music, ElevenLabs voices and a quality gate for images. Most skills need the Scenario MCP server connected with a Scenario account.

Where it fits your pipeline

Slots in at steps 3 and 4, after the story is split into episodes. It helps with consistent cast, wardrobe and location references, storyboards, Kling clip generation, and automated image checks through the quality gate, which may cut manual review. Skills such as scenario-video-assembly, scenario-caption-studio and scenario-audio may also cover joining clips, captions and sound, but the README excerpt does not confirm details. It does not address story, hooks or pacing. The second install command opens a menu where you can pick extra skills such as scenario-kling and scenario-quality-gate.

Install

  • npx skills add scenario-labs/skills --skill scenario
  • npx skills add scenario-labs/skills

Then copy the skill's folder into ~/.claude/skills/.

How to use

Use the scenario skills to build consistent character references for my lead and her rival, generate a storyboard for episode 3 of my micro-drama, then make Kling clips from those references and run the quality gate on the stills.

Claude connects to the Scenario MCP, creates cast references, produces storyboard frames, generates Kling clips, and returns pass/warn/fail verdicts on the images with suggestions to feed into the next generation. Exact results depend on your Scenario account and models.
