What it does

blender-agent-skills is a set of 28 Agent Skills that teach Claude Code how to run professional Blender workflows (verified on Blender 5.3). They cover modeling, UVs, texturing, rigging, animation, clothing, hair, environments, lighting, rendering, video editing, weather, time of day, simulation and QA. Claude writes and runs bpy scripts, either in your open Blender through an optional MCP server or in the background.

Where it fits your pipeline

Slots in at step 3, after episodes are written and before Kling generates clips. It builds consistent 3D locations, props and character stills with controlled lighting, camera and weather, so references stay consistent across shots. It does not help with story, hooks or pacing, and it does not automate review. Requires Blender 5.2 LTS or newer installed locally.

Install

  • /plugin marketplace add EL4CTEO/blender-skills
  • /plugin install blender-agent-skills@blender-agent-skills

How to use

Make this street a rainy night with puddles and lightning, set up a moody camera with a slow push-in, and render a 3-second 1080x1920 clip plus a still of the same shot.

Claude uses the weather, time-of-day, lighting and rendering skills to build the scene in Blender. You get a .blend file and a rendered still or short clip you can use as a reference image or video source. Output quality depends on your assets. The README does not say how well this fits Kling's input needs.
