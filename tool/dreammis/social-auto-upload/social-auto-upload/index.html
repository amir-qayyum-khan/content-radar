What it does

social-auto-upload is an open-source CLI plus a set of Agent Skills that publish videos, articles and image posts to many platforms, including Douyin, Kuaishou, Xiaohongshu, Bilibili, TikTok, YouTube, Facebook and Instagram. You log in once per platform under a local account name, then Claude Code or the sau CLI runs the upload with a title, description, tags and optional scheduling. The repo has a cross-platform entry skill and one skill per platform.

Where it fits your pipeline

It comes after step 5, when ffmpeg has joined the clips into a 1-minute episode. It does not improve story, pacing or review. It removes the manual work of posting each episode to several platforms and can schedule releases. That leaves more of your time for the slow review step.

Install

  • npx skills add dreammis/social-auto-upload --skill douyin-upload

Then copy the skill's folder into ~/.claude/skills/.

How to use

Upload final/episode_01.mp4 to Douyin with the account "creator". Use the title "He lied for 3 years" and a short description with 3 tags, then confirm when it has been submitted.

Claude checks the Douyin session (sau douyin check --account creator) and logs in if needed. It then runs sau douyin upload-video with the file, title, description and tags, and reports whether the upload succeeded. The sau CLI must be installed and you must have logged in once first. The README does not say how long a session lasts.
