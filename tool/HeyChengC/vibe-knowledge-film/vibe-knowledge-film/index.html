What it does

This skill makes 2-5 minute, 16:9 wordless explainer shorts in the style of the Douyin "Vibe knowledge" videos. The viewer reads one subtitle line at the bottom while the screen acts out that sentence. It walks Claude through finding a familiar visual for each concept, writing a storyboard table, and rendering every frame from code (Canvas, Playwright, ffmpeg). It includes two looks, a render engine, and synthesized sound effects.

Where it fits your pipeline

It is an alternative to steps 1-4 for explainer-style content, not for drama. It takes a topic or script and produces a storyboard plus a finished wordless film. It does not feed Kling references or ffmpeg-joined clips. Its useful idea for micro-drama is the discipline of making every line visible on screen, with a hook in the first seconds and a stop-and-draw-or-hold rhythm. It is built for 16:9 explainers with no voice, so it fits knowledge shorts better than vertical micro-drama episodes.

Install

  • pip install -r requirements.txt

Then copy the skill's folder into ~/.claude/skills/.

How to use

Make a vibe knowledge short about why cuckoo eggs fool other birds (supernormal stimuli). Find a familiar visual for each concept, write the storyboard table first, then build the first 30 seconds and show me stills.

A project folder with storyboard.md (one row per subtitle line), film.js, and a rendered 30-second head clip. Stills and contact sheets come first for review. The full renders/final.mp4 and a fact table with sources follow after the opening is approved.
