What it does

motion-skills is a collection of 56 open-source skills in 19 installable packs that teach AI coding agents to build motion graphics, animation and short video, including kinetic typography, data charts, TikTok/Reels clips, b-roll timed to speech, and transparent lower thirds. Each skill uses a render, screenshot and check loop with small helper scripts (freeze a frame, contact sheet, probe the MP4), so the agent inspects its own output. Video skills render through Remotion or Manim.

Where it fits your pipeline

Slots in after the ffmpeg join (step 5) as a finishing layer: it adds hook title cards, kinetic text, lower thirds and b-roll or overlays timed to the words. It does not write the story or generate Kling clips, so it will not fix slow story pacing on its own, but its frame-check loop can speed up reviewing the overlays it makes.

Install

  • npx skills add iart-ai/tiktok-video-skills
  • /plugin marketplace add iart-ai/web-animation-skills

Then copy the skill's folder into ~/.claude/skills/.

How to use

Make a 9:16 vertical title card and kinetic typography opener for my micro-drama episode, with a punchy 2-second hook line, then render it and check a few frames.

A Remotion-based project that renders an MP4 of animated text with timing and easing. The agent freezes frames or builds a contact sheet to check safe areas and legibility, then fixes problems it finds.
