What it does

anidoodle draws illustrations, drawing-timelapse films, explainers and interactive web animations as code in 32 hand-drawn styles (watercolour, woodblock, pixel art, chalk, risograph and more). It can also compose a score in code from 21 music vocabularies and add a kit of 14 seeded sound effects cued to exact frames. The same source redraws the same picture on every machine, so a chosen style stays consistent across everything you make.

Where it fits your pipeline

It is not a story or clip-generation tool, and it does not replace Kling's live-action-style clips. It fits best beside the pipeline, after step 2 (Story to episodes). It can make stylized title cards, recap or cliffhanger stingers, explainer inserts, and animated intros or outros that you join with ffmpeg in step 5. Its music check (key, loudness, masking, novelty) and its sound-effects kit can also add score and stings to an episode, which may help with energy and rising tension. It does not address the slow manual review of clips, and the README does not say it can ingest Kling clips or reference images.

Install

How to use

Make a 20-second chalkboard-style explainer film showing how a three-act micro-drama hook, twist and cliffhanger stack up in a one-minute episode, with a tense synthwave score and a sound effect on each reveal.

A code-drawn film in the chalk style where each mark is drawn in the order a chalk artist would work. It comes with a score composed in code and effects timed to frames. The final frame matches the still exactly. The request is routed to the matching workflow and style automatically. Optional extras like the 373 MB real-instrument sound pack are downloaded only after your agent asks you.
