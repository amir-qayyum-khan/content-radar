What it does

Drama Skills is a set of 12 agent skills that take an idea or a novel through episode scripts, visual setup, storyboards, image and video prompts, editing and review. It keeps creative decisions in plain Markdown files and includes check scripts that catch cross-shot continuity errors and dangling references between documents. Generation of images, video, voice and music is previewed as a batch and only run after you confirm.

Where it fits your pipeline

It fits the story-to-episodes step and carries on into the reference-image and Kling steps. After an idea becomes a story, it writes episode scripts and shot-by-shot storyboards. It then writes first-frame image prompts and motion video prompts that reuse locked wardrobe phrases, so characters stay consistent across clips. It also has an editing skill and review checks. Those can cut some of the manual review work, because the scripts flag broken references and duration mismatches. The README does not show hook, pacing or tension tooling specifically, so its effect on slow, robotic pacing is unclear. Its automation scripts expect a Chinese project structure with fixed Chinese filenames, though the creative guidance itself is language-agnostic. The generation APIs it can call are not named in the README, and it does not say whether it supports Kling.

Install

  • npx skills add zenstory-ai/drama-skills -y -g

Then copy the skill's folder into ~/.claude/skills/.

How to use

/short-drama Read 输入/故事.txt, list the fixed settings, character motives and suspense to hide early, then propose an episode plan (do not just use chapter count as episode count). Write only the EP001 script this round, and for three key shots spell out start and end actions, hand posture, held props and eye direction. Text only: no image, video or voice generation.

A script document (剧本.md) for episode 1 plus the episode plan and the three detailed key-shot descriptions, with no paid generation triggered. Later stages can add 视觉设定.md, 分镜.md, 图片提示词.md and 视频提示词.md, and the check script reports mismatched references or durations.
