What it does

An open-source toolkit that lets Claude Code build explainer-style videos from a sentence or template. It covers the script, AI voiceover, images, music, captions and Remotion rendering, using open models you deploy to your own cloud GPU account. It is aimed at explainers, demos and Shorts rather than scripted drama.

Where it fits your pipeline

It is a poor fit for the core drama pipeline (story, Kling clips, ffmpeg join). It could slot in after step 5 for captions, voiceover or music, loudness and picture checks, vertical cut-downs and publishing to YouTube. It may improve polish and review speed through its automated picture and loudness checks. It does not address slow story or pacing, hooks or rising tension, and I could not confirm any Kling integration from the README.

Install

  • git clone https://github.com/digitalsamba/claude-code-video-toolkit.git

Then copy the skill's folder into ~/.claude/skills/.

How to use

/video Create a 60-second vertical teaser for my micro-drama episode 3. Open with a hook line in the first 2 seconds, add a voiceover, background music and burned-in captions, and use my reference images as scenes.

Claude creates a video project from a template, then walks through script, voiceover, images, music and captions, and renders an MP4 with Remotion. Expect a working render of an explainer or teaser style video. Drama-specific pacing, acting and Kling clip handling are not built in and would need your own direction.
